# 焊接工艺（手工 + 热板回流）

> 本板共 **57 颗**元件，全部在**顶层（单面贴装）**：其中 SMD **49** 颗、插件 **8** 颗，插件焊盘 **69** 个。以下顺序按本板实际位号编排。

## 一、总原则

**先贴片、后插件**；贴片内部 **矮的 → 高的**；怕热、个高的插件放最后。

理由：插件脚一立起来，热风和烙铁就够不到旁边的贴片焊盘了，反过来做必然返工。

## 二、焊接顺序（8 批）

### 第 1 批 · 0603 阻容（28 颗，最矮最密）

| 位号 | 数量 | 规格 |
|---|---|---|
| R1–R8 | 8 | 100Ω（数码管段选限流） |
| R17–R24、R26 | 9 | 10kΩ（上拉 / 下拉） |
| R27–R30 | 4 | 220Ω（LED 限流） |
| C1、C3、C9–C12 | 6 | 100nF |
| C2 | 1 | 10µF |

### 第 2 批 · 0805 阻容（8 颗）

| 位号 | 数量 | 规格 |
|---|---|---|
| R13–R16、R25 | 5 | 1kΩ（三极管基极） |
| C6、C8、C13 | 3 | 10nF |

### 第 3 批 · SOT-23 三极管（5 颗）

- Q1–Q4 = **S8550**（PNP，数码管位选）
- Q5 = **S8050**（NPN，蜂鸣器）

### 第 4 批 · 0805 LED（4 颗）

LED1（红）· LED2（绿）· LED3（蓝）· LED4（黄）

### 第 5 批 · 贴片轻触开关（4 颗）

SW1–SW4（6×6，比较高，放贴片最后）

### 第 6 批 · 插件二极管（2 颗）

D1、D2（1N4148）

### 第 7 批 · 排针 / 排母（3 处）

J1（3P USART）· J2（2P 5V 输入）· U1 的 2 条 1×20P 单排排母

### 第 8 批 · 大件插件（3 颗，最后焊）

DS1（4 位数码管）· BUZ1（蜂鸣器）· V1（CR2032 电池座）

## 三、实操方法：热板回流

实际焊接流程：

1. 先把锡膏点在板上**所有贴片铜皮位置**；
2. 按上面批次顺序，用镊子把 0603、0805 阻容及按键等**全部贴片元件**夹到板上；
3. 焊台加热到有铅锡膏的熔化温度（约 180℃，详见下方注意事项）；
4. 锡膏融化后关闭加热台，每颗贴片元件即焊接固定。

## 四、复盘与注意事项（补充）

1. **锡膏量：宁多勿少。**
   第一版因锡膏太少导致**系统性虚焊**，成功的是第二版。
   经验：锡膏要尽量**覆盖贴片焊盘的全部铜皮**。

2. **温度：以"熔成亮球并润湿铜皮"为准，不要只认 180℃。**
   有铅锡膏（Sn63Pb37）共晶熔点为 **183℃**，"180℃ 就融化"严格说低于熔点；实际能成功，可能来自台面设定值 ≠ 板面实测温度，或停留时间较长。
   复刻时建议台面设 **180–200℃**，以锡膏完全熔化、润湿铜皮为判据——否则容易重复第一版：虚焊常是"锡膏不足 **+** 温度 / 时间不够"**两个原因叠加**。

3. **数量口径。**
   本文 **57 颗** = 需焊接元件数（不含不焊接的核心板；排母按"处"计）；
   BOM 表中 **59 件**含核心板、排母按"件"计，两者是同一批料的不同统计口径。
